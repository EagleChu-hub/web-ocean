## 類似專案 (已驗證)
1. Aureliengmz/clearwater - Real-time, photoreal shallow water in a single HTML file. WebGL2, no libraries
   https://github.com/Aureliengmz/clearwater

2. JesusGalindez/threejs-ocean-simulator-skills - Physically based ocean, sky and boats in a single three.js file, plus skills. Claude, Codex and Gemini.
   https://github.com/JesusGalindez/threejs-ocean-simulator-skills

3. Popov72/OceanDemo - Ocean demo in WebGPU with Babylon.js (FFT-Ocean port)
   https://github.com/Popov72/OceanDemo

4. WebTide / BarthPaleologue/WebTide - Ocean simulation based on Jerry Tessendorf's paper, WebGPU + BabylonJS
   https://github.com/BarthPaleologue/WebTide

5. nff747/ocean-fft-wgsl - Real-Time Phillips Spectrum & Tessendorf Ocean Wave FFT Simulation in WebGPU / WGSL (npm)
   https://github.com/nff747/ocean-fft-wgsl

6. greghuntoon/ocean-waves - Real-time ocean wave simulator — Three.js + custom GLSL Gerstner water
   https://github.com/greghuntoon/ocean-waves

7. owenyuwono/poseidon - GPU-driven real-time FFT ocean (Three.js + WebGPU/TSL)
   https://github.com/owenyuwono/poseidon
